# Онлайн-магазин електроніки (SQLite + Python)

База даних з трьох таблиць (`products`, `customers`, `orders`) та консольний Python-скрипт для роботи з нею.

## Файли

| Файл | Призначення |
|------|-------------|
| `queries.sql` | Усі SQL-запити завдання (пункти 1-9) |
| `database.py` | Клас `ShopDatabase`: підключення через `sqlite3`, виконання запитів, commit/rollback |
| `main.py` | Інтерактивний інтерфейс командного рядка |

## Запуск

Потрібен лише Python 3.8+ (бібліотека `sqlite3` входить до стандартної).

```bash
python main.py
python main.py --db my_shop.db
```

При першому запуску створюється файл `shop.db` з порожніми таблицями. Пункт меню `13` заповнює порожню базу демо-даними.

SQL-скрипт можна виконати окремо:

```bash
sqlite3 shop.db < queries.sql
```

## Меню

| Пункт | Дія |
|-------|-----|
| 1 | Додати товар |
| 2 | Додати клієнта |
| 3 | Створити замовлення |
| 4 | Загальний обсяг продажів |
| 5 | Кількість замовлень кожного клієнта (INNER JOIN) |
| 6 | Середній чек замовлення |
| 7 | Найбільш популярна категорія товарів |
| 8 | Кількість товарів у кожній категорії |
| 9 | Оновлення цін категорії (за замовчуванням смартфони +10%) |
| 10-12 | Перегляд товарів, клієнтів, замовлень |
| 13 | Заповнити порожню базу демо-даними |
| s | Зберегти зміни |
| r | Скасувати незбережені зміни |
| 0 | Вихід |

## Збереження змін

Зміни не записуються в базу автоматично. Після кожної операції, що змінює дані, скрипт питає, чи зберегти зміни. Якщо відповісти «ні», зміни залишаються у відкритій транзакції: їх можна зберегти пунктом `s`, скасувати пунктом `r`, а при виході скрипт запитає ще раз.
